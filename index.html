Simulator Settings & Guide

COA Instruction Set Cheatsheet:

  • MOVE_UP / DOWN / LEFT / RIGHT: Actuates robot grid motion.
  • LOAD Rd, [addr]: Reads Data Memory at [addr] into register Rd.
  • STORE Rs, [addr]: Writes register Rs into Data Memory at [addr].
  • ADD Rd, Rs: ALU computes Rd = Rd + Rs.
  • SUB Rd, Rs: ALU computes Rd = Rd - Rs.
  • HALT: Cleanly terminates CPU execution.
